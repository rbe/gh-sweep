# The confirm screen shows the numbers and the size, and splits the delete into groups with the size of each group

The confirm screen shows the number of artifacts, the number of caches, and the size before the person presses y, with one line for each repository, in a dry run and in a real run.

The confirm screen also splits the checked artifacts into groups, in this order: the expired artifacts, then the active artifacts older than a number of days, then the other checked entries. Each group line shows its count and the space that its delete frees. The person can confirm or skip each group. This follows the cleanup of github-artifacts-analyzer, which asks one question for each group and shows the space that each group frees.

Out of scope: the flag `--summary`. That is the slice [H-2026-11-20-summary-flag](../history/H-2026-11-20-summary-flag.md).
