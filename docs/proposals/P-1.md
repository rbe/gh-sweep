# The confirm screen shows the numbers and the size, and splits the delete into groups with the size of each group

The confirm screen shows the number of artifacts, the number of caches, and the size before the person presses y, with one line for each repository, in a dry run and in a real run.

The confirm screen also splits the checked artifacts into groups, in this order: the expired artifacts, then the active artifacts older than 5 days, which [ADR-0018](../adr/ADR-0018.md) calls old, then the other checked entries. Each group line shows its count and the space that its delete frees. The person can confirm or skip each group.

Out of scope: the flag `--summary`. That is the slice [H-2026-11-20-summary-flag](../history/H-2026-11-20-summary-flag.md).

## Questions and answers

1. Question: what is missing in the dry-run summary? Answer of the owner: among other parts, the summary before the confirm.
2. Question: which part is the first slice? Answer of the owner: `--summary`. The confirm screen waits.
3. Question: does the confirm screen also clean up in groups with a size for each group? Answer of the owner: "Extend [W-2](../ROADMAP.md#w-2) with idea 7." Idea 7 is that grouped cleanup.
4. Question: what is the age limit of the second group? Answer of the owner: "Artifact is old when older than 5 days."
