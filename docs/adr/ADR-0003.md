# The flag --summary prints and exits, and --dry-run keeps the checklist

## Rule

`--summary` prints the summary as plain text to standard output and exits. It opens no checklist, and it sends no delete request. `--dry-run` opens the checklist as before and sends no delete request. A change does not give `--dry-run` the behaviour of `--summary`, and it does not rename either flag.

## Why

A flag is a public name of the tool. A script can depend on it, so the choice is expensive to reverse. Two options were not chosen. `--dry-run` that prints when the output is not a terminal: one flag would then do two things. `--dry-run` that always prints: it would change what the flag does today.
