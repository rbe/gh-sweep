# GitHub is reached through the gh CLI in one package

## Rule

Only the package `internal/gh` starts the `gh` command. No other package calls the GitHub API, and no package uses a GitHub client library or a token of its own. `internal/ui`, `internal/project`, and `internal/format` do not import `os/exec`. The inventory of a repository is read with the `gh` CLI, and its artifacts and caches are put into groups that a person can select (old label D-2).

## Why

The `gh` CLI holds the login in the system keyring. The tool then needs no token handling of its own, and the tests replace one command with `test/mock-gh`. A GitHub client library was not chosen, because it needs a token in the process.
