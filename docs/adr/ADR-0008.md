# Write flags delete entries in named repositories, with filters and --dry-run

## Rule

A write flag deletes or changes entries in each named repository, prints one line for each entry, then a total line, and exits. The first write flags are `--delete-runs` and `--delete-run-logs`. Each write flag follows these rules:

- It needs repository arguments, `--mine`, `--org`, or `--user`. With none of them it is an error, and the tool calls no `gh`.
- With `--dry-run` it reads, writes nothing, and its lines say `would delete`.
- Only one write flag is allowed. A write flag together with a report flag or a settings flag is an error.
- The filter flags `--older-than`, `--branch`, `--status`, `--keep`, and `--untagged` select entries. A filter flag that the write flag does not read is an error. A filter flag with no write flag is an error. A write flag that can take every entry needs at least one filter.
- An error in one repository goes to standard error. The next repository still runs, and the exit status is 1.

`--delete-runs` deletes workflow runs, and GitHub deletes their logs with them. `--delete-run-logs` deletes only the logs. Both take only runs with the status `completed`. `--older-than N` compares the creation time of a run with the clock minus N days. `--branch` and `--status` go to GitHub as query parameters, and the tool refuses a status that the REST API description does not list.

The calls go through `internal/gh`, as [ADR-0001](ADR-0001.md) says. `internal/project` selects the entries and writes the lines.

## Why

A flag is a public name, as [ADR-0003](ADR-0003.md) says. The owner asked that each destructive action has `--dry-run` and a guard against acting on all repositories by accident, as the settings flags of [ADR-0006](ADR-0006.md) have. A required filter keeps `--delete-runs owner/repo` from deleting the whole run history. A run that is not completed still runs or waits, and a delete would stop its record. One filter set for all write flags keeps the names the same across features. Declined: a `created` query parameter for the age, because GitHub then gives at most 1,000 runs.
