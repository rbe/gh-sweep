# The flags --usage and --artifact-list print reports, and the checklist shows them

## Rule

`--usage` prints the storage usage breakdown as plain text and exits. It prints one line for each repository with an artifact or a cache, largest first, then a total line. A line gives the size, the exact byte count, the artifacts, the expired artifacts, the caches, and the share of the total.

`--artifact-list` prints one line for each artifact and exits, then a total line. The repositories keep the order of the arguments, and the artifacts of one repository stand largest first. A line gives the name, the id, the size, the creation date, the expiration date, and the status `active` or `expired`. Dates are UTC, as `2026-11-28`, and an unknown date is `-`. `--artifact-list` reads no cache.

Both flags open no checklist and send no delete request. Only one of `--summary`, `--usage`, and `--artifact-list` is allowed. `--artifact-list` with `--caches-only` is an error. The output of `--summary` does not change.

In the checklist, `u` on the project list shows the usage breakdown of the scanned projects, and `i` inside a project shows its artifact list. An artifact row shows its expiration date. `internal/project` writes the lines of both reports, and the flags and the screens use the same lines.

## Why

The owner chose new flags and new screens, and no change to `--summary`. A script can read `--summary`, so new columns there can break it. A flag is a public name, as [ADR-0003](ADR-0003.md) says. One function for each report keeps the text of a flag and of a screen the same.
