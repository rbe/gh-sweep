# The flag --billing prints the billed Actions usage of an account

## Rule

`--billing` is a read-only flag that runs once for one account. It reads the billing usage summary of this month with `product=Actions`: of the logged-in user, of `--user NAME`, or of `--org NAME` through the organization endpoint. It prints one line for each usage item, with the product, the SKU, the quantity and its unit, and the gross, discount, and net amounts in US dollars, then a total line. A repository argument is an error. An error of GitHub goes to standard error, and the exit status is 1.

## Why

The owner asked for the billed Actions storage of the account. The usage summary gives Actions storage as one SKU among the Actions SKUs, so the flag prints all Actions SKUs. The SKU names come from GitHub and the tool does not filter them by name, because the REST API description does not list the SKU names. A flag is a public name, as [ADR-0003](ADR-0003.md) says.
