# The flags --stale-list and --archive

## Rule

`--stale-list` is a read-only flag. It reads `pushedAt`, `diskUsage`, and `isArchived` with `gh repo list` for the default target, `--org`, or `--user`, and with `gh repo view` for each named repository. It prints one line for each repository, oldest push first, then a total line. `--older-than N` keeps only repositories pushed more than N days ago.

`--archive` is a write flag that needs repository arguments. `--mine`, `--org`, and `--user` are an error, and the tool calls no `gh`. It reads the state of each repository first. An archived repository stays as it is and does not count. With `--older-than N`, a repository pushed in the last N days is an error of that repository, and the next repository still runs. `--dry-run` writes nothing.

## Why

The owner asked to find stale repositories and to archive chosen ones. "Chosen" means named, so the guard of [ADR-0008](ADR-0008.md) is narrower here: a list target is refused. `--older-than` with `--archive` protects against a wrong name in the list. The disk usage of GitHub holds the Git data only, and the README says so.
