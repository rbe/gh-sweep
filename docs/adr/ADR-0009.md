# The flags --delete-caches and --cache-usage

## Rule

`--delete-caches` is a write flag as [ADR-0008](ADR-0008.md) says. It reads the filters `--key-prefix`, `--branch`, and `--older-than`, and needs at least one of them. `--key-prefix` compares the start of the cache key. `--branch NAME` compares the ref with `refs/heads/NAME`. `--older-than` compares the last use of the cache. The tool deletes each selected cache by its id. The total line gives the number and the size.

`--cache-usage` is a read-only flag. It runs in each repository of the target, also the default target, and deletes nothing. It reads `actions/cache/usage`, `actions/cache/storage-limit`, and `actions/cache/retention-limit`, and prints one line for each repository, then a total line. A limit that GitHub refuses is `unknown`. Its error goes to standard error, and the exit status is 1.

## Why

The owner asked to delete caches by key prefix and to see the cache usage and the cache limits. A delete by id was chosen over `DELETE actions/caches?key=`, because a delete by key removes the key on every ref, and the branch and age filters would then take more than they select. The exit status 1 for an unknown limit keeps a script from reading `unknown` as a value.
