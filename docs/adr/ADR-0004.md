# How the checklist reads, groups, and shows a repository

## Rule

A size and a time are shown as short text that a person reads, such as `1.5 MB` and `3d ago`. A repository argument is parsed as `owner/name`. With no repository argument, the tool lists the repositories of the logged-in user. The checklist selects a repository and then a group of artifacts or caches, and it deletes the largest entry first.

## Why

These choices moved here from the old file `docs/DECISIONS.md`, where they were the rows D-1, D-3, D-4, and D-5. A test names each of them, and a person sees each of them on the screen. The old labels stay in this text so that a person can find them.
