# The flags --format and --output write a report as text, JSON, or CSV

## Rule

`--format` takes `text`, `json`, or `csv`. The default is `text`. `--output` takes a file path. Both flags work only with `--summary`, `--usage`, or `--artifact-list`. Without one of these, or with another value of `--format`, the tool prints an error and exits with status 2.

`text` prints the lines of [ADR-0003](ADR-0003.md), [ADR-0005](ADR-0005.md), and [ADR-0007](ADR-0007.md). They do not change.

`json` writes one JSON object, indented by two spaces, with the keys in this order: `report`, `rows`, `skipped`, `total`. `report` is `summary`, `usage`, or `artifact-list`. `rows` is a list with one object for each line of the text report before the skipped lines, in the same order. `skipped` is a list of objects with the keys `repository` and `error`. `total` is one object. A size is an integer number of bytes. A date is an RFC 3339 time in UTC, or `null` when GitHub gave none. An empty list is `[]`, never `null`.

The keys of a row and of the total, in this order:

| Report | Row | Total |
| --- | --- | --- |
| summary | `repository`, `artifacts`, `caches`, `bytes` | `artifacts`, `caches`, `bytes` |
| usage | `repository`, `bytes`, `artifact_bytes`, `expired_artifact_bytes`, `cache_bytes`, `share_percent` | `bytes`, `artifact_bytes`, `expired_artifact_bytes`, `cache_bytes` |
| artifact-list | `repository`, `name`, `id`, `bytes`, `created`, `expires`, `status` | `artifacts`, `bytes`, `expired`, `expired_bytes` |

`share_percent` is a number with one decimal. `id` is a string.

`csv` writes a header record with the row keys of the table, then `status` and `error`. Each row follows with `status` `ok` and an empty `error`. Each skipped repository follows with its `repository`, empty values, `status` `skipped`, and the error. CSV has no total record. The records follow RFC 4180, with a comma and a line feed.

With `--output`, the tool writes the report to that file and nothing to standard output. It creates the file or replaces it, with mode 0644. It writes the file only after it has read every repository. If the tool stops before the first repository, it writes no file. A note, the count of the skipped repositories, and the exit status stay as [ADR-0007](ADR-0007.md) says, on standard error.

`internal/project` builds the rows and writes them as JSON or CSV. `internal/cli` reads the flags and chooses standard output or the file. No import of [ADR-0016](ADR-0016.md) changes.

## Why

The owner asked for idea 1: reports that a script can read. A flag and an output format are public names, so they are expensive to reverse. Sizes in bytes keep the numbers exact, because the text rounds them. A skipped list in JSON and a `status` column in CSV keep a skipped repository visible, as [ADR-0007](ADR-0007.md) asks for the text. Options not chosen: a total record in CSV, because a script that sums the rows would count it twice. One JSON object for each line, because a reader then needs a type key to find the total. The flags `--json` and `--csv`, because two flags for one choice need one more check.
